# CurVE V51.36 — porta visual de acesso

- A Home real permanece visível ao fundo durante o acesso controlado.
- Visitantes e contas sem status `active` recebem um modal bloqueante com Entrar e Solicitar acesso.
- O conteúdo de fundo fica visualmente atenuado/desfocado e sem interação (`inert`).
- Telas de autenticação usam eixo visual comum de 740 px para alinhar cadastro/termos e o modal.
- A proteção de backend da V51.35 permanece inalterada.
- Nenhuma regra de autenticação, telemetria, S/D/F ou API administrativa foi relaxada.
